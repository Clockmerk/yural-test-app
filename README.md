# Поиск автозапчастей (Favorit Parts)

SPA-клиент к [Favorit Parts HS Price API](https://api.favorit-parts.ru/hs/hsprice/): производители по артикулу, аналоги и складские предложения выбранной позиции.

## Стек

- **React 19** + **Vite 7** (JSX, без TypeScript)
- **Redux Toolkit** — ключ и выбранный бренд в слайсе, запросы через RTK Query
- **Bootstrap 5.3** — сетка и базовые контролы
- **Vitest** — unit-тесты доменного слоя

## Архитектура

Двухшаговый сценарий:

1. Ввод ключа и артикула → debounce → `GET` без `analogues` → список производителей
2. Выбор бренда → `GET` с `analogues=on` → таблица предложений (строка = склад)

Слои:

| Слой      | Путь              | Ответственность                                                    |
| --------- | ----------------- | ------------------------------------------------------------------ |
| UI-кит    | `src/ui/`         | Кнопка, поле, селект, карточка, список, кастомный скролл           |
| Экраны    | `src/components/` | Поиск, бренды, предложения, error boundary                         |
| Состояние | `src/store/`      | Слайс экрана и RTK Query: эндпоинты, кэш, статусы, отмена          |
| Домен     | `src/domain/`     | Нормализация ответа в позиции и склады, строки таблицы, сортировка |
| API       | `src/api/`        | Один `fetch` с единым разбором ошибок                              |
| Утилиты   | `src/utils/`      | Приведение типов из ответа, работа со списками, DOM-хелперы        |
| Константы | `src/constants/`  | API, доменные значения (статусы, роли, сортировки), тексты UI      |

Данные с бэкенда проверяются один раз, на входе в `domain/position`: битые поля заменяются запасными значениями, записи без `goodsID` и повторы отсекаются. Компоненты и фильтр работают с уже нормализованными данными.

Запрос производителей уходит после паузы в наборе артикула. RTK Query отменяет предыдущий, когда аргументы меняются, и не повторяет запрос того же бренда, пока ответ есть в кэше.

## Структура

```
src/
  api/           HTTP-клиент проценки
  components/    Составные блоки экрана
  constants/     API, доменные и UI-константы
  domain/        Маппинг ответа, строки таблицы, фильтр и сортировка (+ тесты)
  hooks/         Debounce-поиск по артикулу
  store/         Redux store, searchSlice, селекторы
  ui/            Переиспользуемый UI-кит
  utils/         Приведение типов, списки, DOM (+ тесты)
  App.jsx        Каркас layout
  index.css      Layout, скролл, состояния контролов
```

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Превью сборки: `npm run preview`.

## Проверки

| Команда                | Что делает                        |
| ---------------------- | --------------------------------- |
| `npm run lint`         | ESLint (JS/JSX) и stylelint (CSS) |
| `npm run format:check` | Prettier без записи               |
| `npm test`             | Unit-тесты (Vitest)               |
| `npm run check`        | Формат, линт, тесты и сборка      |

Перед коммитом husky гоняет lint-staged, перед пушем — тесты и сборку. В CI на push и PR: формат, линт, тесты, сборка.

В поле ключа по умолчанию тестовый ключ из документации API. Пример артикула: `01089`.
